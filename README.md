# TechNova — Ultimate Frontend UI Mastery Project


## About the Project

TechNova is a modern technology company website that I created using HTML5 and CSS3. The main purpose of this project was to practice frontend development and create a complete responsive website with multiple pages. I focused on keeping the design clean, simple and easy to use on both desktop and mobile screens.

## Pages Included

The website contains the following pages:

- Home
- About
- Services
- Portfolio
- Gallery
- Pricing
- Team
- Blog
- Testimonials
- FAQ
- Contact
- Login
- Register
- Dashboard
- 404 Page

## Technologies Used

- HTML5
- CSS3

I have not used any frontend framework or CSS framework in this project. The website is made using basic HTML and CSS.

## HTML Features Used

Some of the HTML5 features used in this project are:

- Semantic HTML elements
- Forms and form validation
- Tables
- Lists
- Images
- Figure and figcaption
- Audio and video
- Details and summary
- Progress and meter
- Links and navigation
- Different types of input fields

## CSS Features Used

I used CSS for the complete design and layout of the website.

Some of the CSS concepts used are:

- Flexbox
- CSS Grid
- Media queries
- Responsive design
- Hover effects
- Transitions
- Animations
- Gradients
- Shadows
- Borders and border radius
- Positioning
- Pseudo-classes
- Pseudo-elements
- Responsive typography
