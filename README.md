# Project Title

TechNova - Modern Technology Company Website

## Project Description

TechNova is a modern technology company website created using HTML5 and CSS3. The main purpose of this project was to practice frontend development and create a complete website with multiple pages. I focused on keeping the design clean, simple and responsive for different screen sizes.

## Technology Stack

- HTML5
- CSS3

## Features

- Multi-page website
- Responsive design
- Navigation bar with different pages
- Services section
- Portfolio section
- Gallery page
- Pricing section
- Team section
- Testimonials section
- FAQ section
- Contact form
- Login and registration pages
- Dashboard page
- 404 error page
- CSS animations
- Responsive layouts


## Steps to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in the browser.
4. You can also use the Live Server extension in VS Code.
5. Use the navigation menu to visit the different pages.
